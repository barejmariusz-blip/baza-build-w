# Baza Buildów

Program na Windows do zapisywania i szybkiego wyszukiwania buildów do gier (linki, pełny build w środku, tagi, status, screeny).

## Pobieranie
Najnowszy `BazaBuildow.exe` jest w zakładce **Releases** (budowany automatycznie przy każdej zmianie w `main`).

## Dane
- Domyślnie: `Dokumenty\BazaBuildow\` (folder można zmienić w programie)
- `buildy.json` – baza, `obrazy\` – screeny, `kopie\` – kopie dzienne (ostatnie 60)
- Wymaga Microsoft Edge WebView2 (wbudowany w Windows 10/11).
